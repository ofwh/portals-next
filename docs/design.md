# 设计规范

本规范约束业务页面与组件的布局、展示和交互。业务默认行为通过组件公开属性配置，样式按下述边界维护。

## 组件与样式边界

- 优先复用本地已有组件；缺少对应组件时，通过 `pnpm dlx shadcn@latest add <name>` 安装。
- `components/` 仅存放组件；非组件 TypeScript 模块按职责放入 `lib/`、`hooks/` 或 `stores/` 等对应目录。`components/app/` 下的组件及其导出入口统一使用 `.tsx` 扩展名，不放置 `.ts` 模块。
- 不修改 `components/ui`，保持 shadcn 提供的原始代码。业务组合与交互放在业务组件中，通过组件公开属性扩展展示。
- 页面与业务组件的局部布局、间距和尺寸使用 Tailwind `className`，不为局部布局增加公共覆盖规则。
- 应用通用的组件与表单覆盖统一维护在 `styles/ui.module.css`，不放入 `app/globals.css`；由根布局统一加载，使页面内组件与 Portal 弹层采用相同规则。
- 通用覆盖优先使用组件已有的 `data-slot`、方向与状态属性选择器，不增加供业务逐个挂载的样式类。字段高亮是例外，保留该模块的 `highlight` 类，不迁移或移除，其使用范围见[悬停、焦点与状态反馈](#悬停焦点与状态反馈)。
- 覆盖样式使用原生 CSS 与主题变量，不依赖 `@apply`。通用属性选择器以 `:where(body)` 限定文档作用域，兼容 Turbopack 的 CSS Modules 校验且不增加选择器权重；不依赖禁用纯选择器检查的注释。容器查询不得依赖被 CSS Modules 局部化后无法匹配的外部容器名称。
- 颜色、圆角、边框和焦点样式沿用应用主题变量与现有组件，兼容明暗主题。正文使用前景色，说明使用弱化前景色，错误与危险操作使用语义化危险色。
- 文案与语言遵循[国际化规范](i18n.md)，主题及时间展示遵循[偏好设置](preferences.md)。

## 页面布局

- 后台页面复用应用外壳，由外壳负责侧栏、顶栏与主内容区留白。
- 页面主体居中并限制最大宽度；列表页保留较宽内容区，设置表单使用较窄阅读宽度。页面内容与文本默认左对齐，居中容器不代表居中文本。
- 页头包含主标题与下方弱化说明，主要操作在宽屏位于右侧，窄屏纵向排列。
- 搜索与筛选位于列表上方，宽屏横向排列，窄屏纵向排列；刷新与批量操作单独成组。
- 表格使用带边框和圆角的容器、弱化表头背景与行悬停反馈。常规内容左对齐，操作列表头与按钮组居中，分页区靠右并允许换行。
- 宽表格在容器内横向滚动，不挤压列内容导致页面整体溢出。长名称与地址按可用空间截断，通过 Tooltip 补充完整内容；弹层中的长文本允许换行。

## 表单结构与对齐

### form 与字段组

- 业务表单直接使用原生 `form` 和 shadcn Field 系列组件，不增加公共 Form 封装。业务行为由业务组件与 `hooks/` 中的业务 hooks 处理。
- `form` 占满所属内容区的可用宽度，字段按单列纵向排列，不对整个表单使用水平或垂直居中布局。表单所在页面的居中限宽遵循页面布局规则。
- 抽屉中的 `form` 使用纵向 flex 布局并占据剩余高度，设置 `min-h-0` 允许字段区收缩；滚动由字段区承担，底部操作区不随字段滚走。页面内的 `form` 按内容自然撑高，随页面滚动。
- 相关字段通过 `FieldGroup` 纵向组合，需要标题的分组使用 `FieldSet` 与 `FieldLegend`。分组标题位于字段上方并左对齐，组间留白大于紧凑字段行之间的留白。
- 抽屉字段组使用紧凑行间距，字段内边距由公共高亮样式提供；页面设置表单沿用 Field 系列的分组间距，字段及表单分组之间不使用分割线。间距由容器统一控制，不以各字段独立添加外边距拼接。

### Field 行与内部元素

- 每个字段使用占满组宽度的 `Field`。水平与响应式字段的直接布局分为说明列 `FieldContent` 和以 `data-slot="field-control"` 标识的控件容器；说明列内部按标签、说明的顺序纵向排列。
- 公共对齐与尺寸规则遵循[组件与样式边界](#组件与样式边界)，仅在对应字段方向生效，不改变默认纵向字段的布局；分组间距与个别控件尺寸由业务组件声明，不在每个字段重复添加已有公共规则。
- 抽屉表单显式使用 `orientation="horizontal"`，不依赖 Field 的默认纵向布局。说明列默认固定占字段宽度的 35%，不参与伸缩；控件容器占据扣除说明列和列间距后的剩余宽度。同组字段的列边界保持一致，不随标签字数或控件类型变化；需要调整说明列比例时使用 `--field-label-width`。
- 水平 Field 的两个直接子项按顶部对齐。控件容器拉伸至字段行高度，其内部使用垂直居中、水平靠右的 flex 对齐；标签与说明保持顶部起排。字段行高度由较高的一侧内容自然撑开。
- 说明列、控件容器及需要收缩的分组允许收缩内容宽度，避免长文本撑破布局；说明列本身的宽度不被输入控件挤占。
- 页面设置表单使用 `orientation="responsive"`，依据 `FieldGroup` 的容器空间切换：宽容器沿用左右分栏；窄容器中说明列与控件区均占满宽度，标签在上、控件在下，控件靠左。横向布局的列宽与对齐仅在对应容器断点生效。

| 元素                               | 展示与对齐                                                               |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `FieldLabel`                       | 位于说明列顶部，左对齐，沿用组件的标签字重，不设统一固定高度             |
| `FieldDescription`                 | 紧接标签下方，左对齐，使用弱化颜色与常规字重，不与标签横排或移入占位符   |
| 单行输入、多行输入、组合输入       | 填满控件区可用宽度，输入文本左对齐，多行内容从顶部开始                   |
| 下拉选择触发器                     | 表单录入字段填满控件区；紧凑设置选择器按内容宽度展示，并遵循控件区对齐   |
| 开关、分段选项、单选组、颜色触发器 | 保持自身尺寸，在控件区靠右并垂直居中，选项较多时允许换行                 |
| 预览与只读展示                     | 使用同一说明列与控件区结构，预览在控件区靠右并垂直居中                   |
| 多行复合控件                       | 整体填满控件区，内部按行纵向排列，行内输入允许收缩，操作按钮保持自身尺寸 |

- 上表中“靠右”适用于水平字段；响应式字段切换为纵向后按窄容器规则靠左。控件区的右对齐不改变输入文本、标签或说明的文本对齐。
- 标签与说明允许自然换行及长词断行，不截断、不强制单行；说明变长时由整行扩高，不覆盖相邻字段。条件隐藏的字段不保留空白行。

### 字段语义与输入行为

- 标签通过 `htmlFor` 关联控件；组合控件通过 `aria-labelledby` 关联标签，说明通过 `aria-describedby` 关联。必填字段设置原生 `required`，展示必填标记时使用危险色，并对辅助技术隐藏装饰标记。
- 表单中的非提交按钮显式设置 `type="button"`，提交操作使用 `type="submit"`。多行文本允许纵向调整，结构化文本使用等宽字体。

## 表单承载与操作

- 列表内的新增与编辑使用右侧 Drawer，显式设置 `swipeDirection="right"`；窄屏占满宽度，宽屏限制宽度。
- 抽屉由标题说明区、可独立纵向滚动的字段区与底部操作区组成。标题区和底部操作区以边框分隔，关闭按钮位于右上角。
- 抽屉操作区在宽屏靠右横排，窄屏沿用 DrawerFooter 的纵向布局；取消使用描边按钮，保存或创建使用主按钮，错误信息显示在操作区。
- 页面表单的提交操作位于表单末尾并靠右。即时生效控件与提交后生效字段保持各自保存语义，不由公共布局统一触发保存。
- 提交中禁用相关字段与重复操作，提交按钮显示加载反馈；抽屉提交期间禁止关闭。加载失败提供重试，未加载完成时禁止提交。

## 弹层展示

下表为业务调用约定；位置指首选方向，边界碰撞调整与焦点管理交由底层组件处理。

| 场景                                      | 默认展示               | 实现约束                                                                       |
| ----------------------------------------- | ---------------------- | ------------------------------------------------------------------------------ |
| Popover，包括就地确认、补充内容和选择面板 | 触发器上方，水平居中   | 显式传入 `side="top"`、`align="center"`；不继承底层 Popover 的下方默认值       |
| Tooltip                                   | 触发器上方，水平居中   | 使用 `side="top"`，沿用居中对齐；仅展示提示内容                                |
| Select                                    | 触发器下方，水平居中   | 使用 `side="bottom"`、`alignItemWithTrigger={false}`，不以选中项覆盖触发器定位 |
| Combobox                                  | 输入区下方，起始边对齐 | 使用 `side="bottom"`，沿用起始边对齐；组合输入区作为锚点时，关联整个输入区     |
| 顶栏紧凑菜单                              | 触发器下方，末端对齐   | 使用 DropdownMenu，设置 `align="end"`                                          |

- 弹层与触发器保持组件默认间距，沿用组件的层级、阴影和开合动画，不在页面中手动计算绝对定位。
- 对齐描述针对弹层与触发器的关系；弹层正文默认左对齐，不因 `align="center"` 改成居中文本。
- 选择列表通常跟随锚点宽度；内容需要更宽时可扩展，但不得超出可用视口。内容较多时在弹层内部滚动或换行。
- 危险操作使用就地确认 Popover，包含标题、说明、取消与危险确认按钮；按钮组靠右，错误留在弹层内，执行中禁用重复操作。
- Tooltip 用于图标操作说明和截断内容补充；无提示内容时禁用。交互内容使用 Popover，不放入 Tooltip。图标按钮仍需提供可访问名称。

## 悬停、焦点与状态反馈

- 抽屉业务表单在 `form` 上应用公共 `highlight` 样式，以整个 Field 为悬停区域，使用弱化背景、圆角与背景色过渡；不单独复制到标签或控件上。页面设置表单按[form 与字段组](#form-与字段组)组织内容，不默认套用该高亮。
- 按钮、表格行与选择项沿用现有组件的悬停、焦点、选中和禁用反馈；保留键盘焦点环，不能仅靠 hover 表达可操作状态。
- 选择列表中的标签保留自身配置的配色，列表项悬停或高亮不得覆盖标签的背景色与文字色。
- 已选标签的移除按钮需有独立的悬停与键盘焦点反馈，颜色和圆角与所在标签协调；公共样式通过按钮的 `data-slot` 定位。
- 随行悬停显示的辅助操作同时在 `focus-visible` 时显示，不能只支持鼠标悬停。
- 初次列表加载使用骨架占位，已有数据刷新时保留内容并展示顶部进度反馈；空数据与筛选无结果使用各自提示。
- 错误信息使用 `role="alert"`，加载与空状态提供状态语义，列表加载使用 `aria-busy`。操作结果使用现有 Toast，不能替代表单或确认弹层中的错误反馈。
