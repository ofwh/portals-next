# 设置模块

各设置模块独立定义配置结构、校验、访问权限和持久化策略，通过明确接口组合，不将其他业务配置归入偏好模块。接口分层与更新约定遵循 [API 规范](api.md)。

store 维护模块数据、请求和状态；业务 hooks 提供该模块的读写与派生能力；页面入口组合初始化、刷新和展示。读取 hook 不自动重复触发初始化请求。

认证模块提供会话信息，不读取或写入业务设置。需要登录的设置由接口鉴权；会话尚未确认或获取失败时，不得按未登录处理写入。是否允许浏览器本地保存由各模块定义，不能将偏好设置的 Cookie 回落规则套用到其他账号或系统配置。

具体偏好的数据源与 Cookie 规则见[偏好设置](preferences.md)。
