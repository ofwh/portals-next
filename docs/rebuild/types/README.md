# 公共数据契约

| 数据        | 内容与所有者                                                                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| ProxyNode   | 可序列化的协议判别对象，含名称、端点和协议字段组。字段由[节点模块](../providers/字段归一化.md)冻结                                             |
| ProxyGroup  | 有序分组声明。name、kind、selectors、providerRefs、探测选项及组专属选项。selectors 保存字面引用、正则或带来源条件的匹配描述                    |
| RuleSet     | 有序规则来源声明。目标、正文类别、来源、周期、选项。来源为内联 Rule 或资源地址；Rule 存放类型、有序参数、flags。资源展开结果通过明确关联键交付 |
| Template<T> | 格式标记和解析后的完整文档 T，保持未知字段和数据类型。驱动决定如何复制和修改                                                                   |
| Diagnostic  | 严重程度、错误码、来源位置和脱敏上下文。按条目失败与整体输入失败分别建模                                                                       |

约定明确单位，区分缺省与显式零值/false。公共数据不携带客户端编码结果、解析器回调、网络句柄或运行时状态。只有编译阶段分配目标名称。若需要稳定追踪重名节点，使用列表索引或显式来源身份，禁止以展示名称作为唯一键。
