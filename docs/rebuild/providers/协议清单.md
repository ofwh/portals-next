# 输入协议批量勾选

每行对应一个启用项。调用方选择启用项，每项包含其明确列出的变体。清单以仓库的 [Mihomo scheme 表](/Users/larify/Documents/github/SubConverter-Extended/src/parser/mihomo_schemes.h)、[旧单链入口](/Users/larify/Documents/github/SubConverter-Extended/src/parser/subparser.cpp:5896)和 [ProxyType](/Users/larify/Documents/github/SubConverter-Extended/src/parser/config/proxy.h)为范围。生成表表示桥的识别范围，具体 URI 字段仍需用样例验证。

| 规范协议     | URI/变体                                                                    |
| ------------ | --------------------------------------------------------------------------- |
| Shadowsocks  | ss                                                                          |
| ShadowsocksR | ssr                                                                         |
| VMess        | vmess、vmess1                                                               |
| VLESS        | vless、vless1                                                               |
| Trojan       | trojan、trojan-go，按变体校验                                               |
| SOCKS5       | socks、socks5、socks5h、Telegram socks 分享                                 |
| HTTP         | http、Telegram http 分享                                                    |
| HTTPS        | https，普通订阅 URL 不能当节点                                              |
| Hysteria     | hysteria、hy                                                                |
| Hysteria2    | hysteria2、hy2；Realm 变体 hysteria2+realm、hy2+realm、hysteria2+realm+http |
| TUIC         | tuic                                                                        |
| AnyTLS       | anytls                                                                      |
| Naive        | naive+https、naive+quic                                                     |
| WireGuard    | wireguard                                                                   |
| Mieru        | mierus、mieru；一条资源可能含多个端口/传输绑定                              |

Netch 包装属于独立的兼容范围。Snell 在旧结构化配置及输出模型中出现，旧单链分派及 Mihomo scheme 表均无独立 Snell 入口，需有明确 URI 契约后才能加入勾选表。

输入与目标驱动的输出支持范围分别确定。
