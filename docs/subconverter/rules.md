# 规则解析

## 契约与边界

[规则 parser](../../lib/subconverter/rulesets/index.ts) 接收配置树及客户端类型，返回通用规则定义。配置树由[配置解析器](configuration.md)提供；解析分层及客户端选择见[客户端解析选择](README.md#客户端解析选择)。

数据集读取负责路径、别名和字段形状，客户端解析器处理字段支持范围，公共转换器处理字符串与对象到通用字段的转换。不修改输入配置树。

## 配方路径与字段

根级 `rulesets` 优先读取对象列表；否则读取 `custom.rulesets`，缺失时依次选择 `custom.ruleset*`、`custom.surge_ruleset*`。别名按键是否存在判断，空的新字段不回落。缺失对应配置区域报错；显式空列表允许返回空数组。

对象必须提供 group；rule 与 ruleset 互斥。rule 表示内联条件；ruleset 表示来源，`[]` 前缀表示内联条件。type 指定远程来源格式，省略时从来源前缀推导，无前缀时使用 Surge。显式 type 的来源不再次剥离前缀。字段形状以[业务类型](../../lib/subconverter/types/rulesets.ts)为准。

字符串以第一个逗号分开策略与来源。来源以 `[]` 开头时，其余文本整体作为规则条件；远程来源的最后一个逗号分开来源和 `interval|option...`，缺失间隔使用默认值。已知来源前缀决定来源格式并从 URL 移除。

## 选项与错误

no-resolve 映射 noResolve，stash-format 映射资源格式。选项去除首尾空白并转小写；未知选项报字段错误，冲突的有效资源格式报字段错误。客户端解析器校验选项是否适用于所选客户端。

缺少必要字段、非法字段形状、互斥字段同时出现或非法数字均报字段错误。未展开的 `!!import:` 或对象 import 必须拒绝；加载职责见[其余配置](other-options.md#加载与运行参数)。

规则来源格式与客户端类型独立。内联规则在解析阶段校验语法及客户端支持范围；远程资源不在解析阶段下载，其正文校验、策略绑定及最终投影由[输出适配器](output-adapter.md)负责。
