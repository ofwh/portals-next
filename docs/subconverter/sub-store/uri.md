# URI 输出类型

依据：[uri.js](https://github.com/sub-store-org/Sub-Store/blob/352f01b7091c99f4e219c44e4ec96f3288059843/backend/src/core/proxy-utils/producers/uri.js)。表格的类型和缺省语义遵守[阅读约定](README.md#阅读约定)。

## schema

String，逐节点使用自身 scheme。普通 SS 示例：

```text
ss://YWVzLTEyOC1nY206c2VjcmV0@proxy.example.com:443?udp=1#Example
```

VMess JSON、SSR 的主体先做内部 Base64；其他 URL query/fragment 分别转义。此 producer 本身不做订阅整体 Base64。

## 能力与约束

这是 Sub-Store 的实际兼容方言，不等于所有协议的正式规范。SS 支持 UDP query；其他类型按自己的分支处理。URI producer 无默认未知类型抛错，未命中分支可能返回空 String；宿主不应把空行当有效节点。没有 Mieru/HTTP/Snell 的 URI 输出分支。IPv6 使用方括号；认证值不能在解码后再按冒号任意拆分。
