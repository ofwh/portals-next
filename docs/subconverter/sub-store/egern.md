# Egern 输出类型

依据：[egern.js](https://github.com/sub-store-org/Sub-Store/blob/352f01b7091c99f4e219c44e4ec96f3288059843/backend/src/core/proxy-utils/producers/egern.js)。表格的类型和缺省语义遵守[阅读约定](README.md#阅读约定)。

## schema

YAML keyed union：

```yaml
proxies:
  - shadowsocks:
      name: Example
      server: proxy.example.com
      port: 443
      method: aes-128-gcm
      password: secret
```

## 参数

全部显式字段、嵌套路径、私有输入、删除规则、枚举及动态参数见[逐参数全表](parameters/egern.md)。以下表格解释主要字段的协议语义；共享字段通过公共表完整维护。

| TLS                       | `sni`                                           | `String`                     | tls=true 且缺省时为 server                    | 否                | 未限定                            | `tls.example.com`                                                                                             | 按输入条件输出                                         |

## 能力与约束

白名单：HTTP、HTTPS、SOCKS5、SS、SSR、Trojan、Hysteria2、VLESS、VMess、TUIC、WireGuard、AnyTLS、SSH、Snell。gRPC/REALITY、SSR、Snell 等有额外校验；生成结果内部使用包装协议名，不能加回内部 type 后当作等价结构。
