# v2ray 显式参数全表

来源：[v2ray.js](https://github.com/sub-store-org/Sub-Store/blob/352f01b7091c99f4e219c44e4ec96f3288059843/backend/src/core/proxy-utils/producers/v2ray.js)。本页覆盖该 producer 中所有显式读取、构造、模板输出、删除和动态遍历的参数位置。每个字段按协议或函数作用域区分，不能把不同分支的类型和缺省值合并为全局默认。

字段类型来自显式构造或类型转换时直接记录；仅按规范化输入词汇识别的类型标为“来源约定”，不冒充此 producer 的运行时校验。源码无类型约束的透传值保留为 JSONValue。必须性中的“直接拼接”不表示源码验证了输入。

## 开放参数与完整性边界

JSONValue 定义为 String、Number、Boolean、null、Array<JSONValue> 或 Object<String,JSONValue>。根对象或嵌套对象被整体透传、spread、合并或 Object.keys/entries 遍历时，其键集合是开放的；对应行以 `*` 或计算键记录，并给出来源位置。该开放规则覆盖任意合法键，不以人工枚举替代，也不保证目标客户端接受这些键。
