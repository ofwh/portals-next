# sing-box 输出类型

依据：[sing-box.js](https://github.com/sub-store-org/Sub-Store/blob/352f01b7091c99f4e219c44e4ec96f3288059843/backend/src/core/proxy-utils/producers/sing-box.js)。表格的类型和缺省语义遵守[阅读约定](README.md#阅读约定)。

## schema

JSON 节点片段，不含路由、DNS、策略组。

```json
{
  "outbounds": [
    {
      "type": "shadowsocks",
      "tag": "Example",
      "server": "proxy.example.com",
      "server_port": 443,
      "method": "aes-128-gcm",
      "password": "secret"
    }
  ],
  "endpoints": []
}
```

## 能力与约束

WireGuard/Tailscale 放 endpoints；其他放 outbounds。支持分支不能直接等同于客户端当前版本能力：SSR 默认被跳过，仅 include-unsupported-proxy 时继续；Snell 版本和模式按分支限制。ShadowTLS 可拆为多个 outbound，以 detour 连接，不能把它误写成 SS plugin。无效节点转换失败时回滚该节点已追加的所有产物。
