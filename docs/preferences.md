# 偏好设置

模块职责与组合方式遵循[设置模块规范](settings.md)。

偏好设置在服务端维护一份全局配置，不关联用户。配置以设置键作为主键，不增加独立记录标识。

已登录时，主题、语言和时间格式分别按数据库、当前请求 Cookie、默认值的顺序读取，每个字段独立校验并回落。服务端页面、业务 API 和客户端初始化使用同一解析规则，Cookie 不覆盖有效的数据库配置。未登录时仅读取当前浏览器的 Cookie 与默认值，不读取服务端配置。

已登录时，偏好接口负责读取、保存配置并通过响应写入 Cookie。登录成功后的页面跳转或刷新通过偏好读取接口同步数据库配置，认证回调与鉴权层不处理偏好。未登录时仅在客户端保存 Cookie，不修改数据库。Cookie 字段为 `theme`、`language`、`timeFormat`，使用 `Path=/`，供页面与 API 读取。数据库更新遵循 [API 规范](api.md)。

`usePreferences` 提供读写与时间格式化能力，不承担挂载时的自动初始化。页面入口通过 Provider 组合一次初始化和同步，其他调用方按需读取状态或调用操作。
