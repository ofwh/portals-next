# 工作流节点开发

开始前读取仓库根目录 [AGENTS.md](../../../AGENTS.md)。接口与业务错误遵守 [API 规范](../../api.md)，视图遵守[设计规范](../../design.md)，文案遵守[国际化规范](../../i18n.md)。

## 确定边界

从用户要求确定节点所属组、输入输出语义、配置草稿和执行行为。先检查已有节点与核心能力，仅在需求和源码均不能确定业务语义时询问用户。不附带生成页面、无关节点或执行引擎。

实现前读取 `lib/workflow/nodes/types.ts` 与 `lib/workflow/nodes/core/` 的实际契约；接口签名、类型定义和核心能力以源码为准，不在技能维护副本。节点定义、画布实例与单次运行状态分别处理，运行状态不写入定义或配置草稿。

## 单节点目录与依赖

节点实现位于所属节点组内。根目录仅保留后端组装入口 `index.ts` 与前端视图入口 `client.ts`，内部按以下职责组织，文件按实际能力创建，不补空模块：

- `model/`：definition 保存标识、版本、默认配置与选项；types 保存公开配置、输入输出类型；schema 保存校验与类型守卫。可供前后端共同引用，不依赖 UI、运行服务或服务端模块。
- `runtime/`：input 适配配置与上游值，executor 对接执行上下文，service 实现业务规则。辅助模块按职责就近保存；仅运行模块共享的类型不放入公开模型。
- `ui/`：config 实现配置表单，view 提供图标和可选画布内容，index 组装节点视图。只引用共享模型和前端安全模块，不引用运行服务或后端组装入口。

普通节点保持一层职责子目录，具有独立职责的子模块按需增加层级。私有类型就近声明，共享能力仅在多个节点确有需要时上移到节点组或公共模块。供共享校验使用的辅助函数保持前端安全，与共享模型一同维护。

内部模块直接引用具体文件，仅注册入口或需统一管理的模块集合聚合导出。

## 节点组国际化

节点组的名称、节点名称、配置表单、展示内容及组内专属错误翻译统一维护在该组的 `i18n/`，按语言组织，组内共享文案集中复用。节点文案使用独立命名空间，不绑定宿主页面路由，不在全局语言包重复定义。

错误码定义及响应处理遵守 API 规范，组内专属错误翻译通过错误消息聚合层接入，不混入页面消息。

新增或移除节点组时同步处理消息聚合入口；核对名称、表单、展示和错误翻译的引用完整性，避免在组外遗留专属文案。

## 数据契约与解析执行

输入、配置、输出及执行输入绑定对应的运行时 schema，数组元素、字典值和联合分支均须保留类型信息。运行时描述显式声明，不依赖 TypeScript 类型名称推断。

专用业务类型通过 ref 注册校验器及基础结构。前后端需要类型匹配时加载同一安全定义，不维护另一套连线判定。连线按输出可赋给输入判断，不依据节点名称或分组：

- 数组与字典递归检查元素或值；数组不隐式转换为单值，多条连线不等同于一条数组输入。
- 联合输出的所有分支均须被目标接受；目标为联合类型时匹配可接受的分支。
- 运行时 any 描述可接收其他类型，但不能直接赋给具体类型；未绑定泛型不能退化为 any。此描述不放宽 AGENTS.md 的 TypeScript 类型要求。
- 同一 ref 与版本可兼容；ref 到通用结构仅沿注册的 base 判断。通用结构到 ref、不同 ref 之间不隐式升级，须显式转换或校验。

来源节点声明无输入端口，无输出节点声明无输出端口；端口必需性与多连线能力由契约明确表达。允许空数组输出；数组展开、文本拼接由节点显式实现。

解析与执行按以下边界实现：

- schema 验证真实输入、输出或配置结构；配置草稿结构判断与严格执行校验分离。
- parseConfig 调用配置校验并完成必要转换，在执行前发现非法参数及正则等错误。
- parseInput 组装已校验的上游值，明确单值、多输入与展开语义，保留引擎传入的连线顺序。
- execute 仅处理解析后的参数，返回约定输出；异步业务处理响应执行上下文的取消信号。

复用注册中心的输入输出校验包装，不绕过 schema。参与快照或状态传输的数据须可 JSON 序列化，不传递函数、循环对象或 Blob；资源使用 URL 或明确的数据结构。业务处理在后端完成，节点不自行管理 SSE、全局运行状态或调度。

## 配置与视图

同一 Config 类型由节点定义、配置表单和展示视图共同使用。默认配置提供完整初始结构，每次创建实例深拷贝。编辑中的空字符串、空数组等由类型明确表达，不使用任意缺字段的 Partial 代替草稿模型。

配置仅保存 JSON 数据；需保留数字输入的中间状态时可存字符串，由配置解析转换。正则保存表达式文本，组件和函数不进入配置。视图注册的 isConfig 接受合法的未完成草稿，后端在运行前独立严格校验；保存草稿不等于执行校验通过。

表单通过 Form 契约接入并保持受控，仅通过 value/onChange 返回完整配置；数组编辑完整替换，清空使用约定空值。不得直接操作画布 store、localStorage 或执行器。公共控件复用，动态字段由节点实现；前端校验使用字段路径反馈错误。

画布统一承载弹窗、保存取消、选中状态、连接点和拖拽。表单编辑只更新草稿，保存后写入实例，取消或关闭丢弃修改。节点只负责字段及内容布局，不自行创建连接点或移动实例。

前端入口提供图标、配置表单及可选 display。详情开关由画布控制；未定义 display 或未展开时使用统一预览。左侧列表使用统一样式和注册图标，不渲染节点 Content；节点不自行实现拖动预览。

size 使用未缩放的逻辑像素，内容限制在声明尺寸内，通过截断或内部滚动处理溢出，不隐式撑大外框。Content 只读配置，配置变化即重新渲染，无需执行节点；网络请求和业务处理通过后端执行流程完成。视图、组件和尺寸不写入快照，恢复时按 type 匹配视图并回填配置。

## 注册与版本

节点 type 全局唯一，与实例 id 区分。后端入口组装模型、参数适配与执行入口；前端入口独立导出视图，通过相同 type 对应后端能力。

节点组后端入口默认导出完整节点列表，并具名导出满足 NodeModuleGroup 的 group，包含组信息、节点及所需专用类型；前端入口独立完成视图注册。全局入口仅通过组入口注册，不逐个引用子节点，不在页面增加节点专用分支。专用类型在使用前完成注册，跨组 ref 依赖不得受展示顺序影响。

清单由注册信息生成，仅含可序列化能力描述，不携带执行或服务端解析函数。组按注册调用顺序展示，组内按传入数组顺序展示，本地化与前端不得重新排序。

实例的节点实现版本来自注册清单，后端执行时逐个比对；流程版本不能代替节点版本。修改持久化配置结构时明确兼容或迁移方式，不得只修改版本标记以绕过校验。恢复或迁移失败保留原数据，未知节点不静默删除；运行结果和瞬时状态不写回配置。

## 检查与交付

按仓库现有命令执行类型、lint 和相关文件格式检查，核对节点组入口和跨节点引用，从前端入口审查模型、视图及共享辅助函数的依赖链。测试相关工作遵守 AGENTS.md。

交付说明包含节点行为、接入位置、检查结果及实际限制。
